# LumLump

Website LumLump untuk menampilkan menu lumpia dan menerima pesanan melalui
WhatsApp.

## Menjalankan secara lokal

```sh
pnpm install
pnpm dev
```

## GitHub Pages

Setiap push ke branch `main` menjalankan workflow GitHub Actions untuk
membangun dan menerbitkan situs ke
<https://plnvxtf.github.io/LumLump/>.

Testimoni yang dikirim pengunjung disimpan di penyimpanan lokal browser dan
berstatus menunggu persetujuan. Tanpa backend, testimoni tersebut tidak
tersinkron ke perangkat lain atau terkirim ke pemilik situs.
